Hybrid retrieval + reranking QA

Answers questions over 2,067 Wikipedia passages and cites the passage it used. Each stage is benchmarked so every component has to earn its place.

Recall@1 0.74 → 0.88Recall@20 0.9978.3 F1 end-to-end
  • BM25 written from scratch on a sparse term-document matrix
  • Dense bi-encoder retrieval fused with BM25 by reciprocal rank fusion
  • Cross-encoder reranking of the top 20, then a sliding-window extractive reader
  • Loses only ~7 F1 versus a reader handed the gold passage
